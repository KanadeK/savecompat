## [0.1.0] - 2026-07-28

### Added

- Engine-agnostic JSON save migration graph and deterministic operation DSL.
- Source and per-step JSON Schema validation.
- Critical-value preservation rules.
- ID-keyed semantic diff for game entity arrays.
- Corpus checking with JSON and self-contained HTML reports.
- Safe output, non-overwrite default, timestamped backup, and atomic in-place replacement.
- `doctor`, `check`, `migrate`, `diff`, and `init` CLI commands.
- TypeScript library exports.
- Three-version Space Trader example corpus.
- Unit, integration, coverage, smoke, CI, Pages, and release workflows.
